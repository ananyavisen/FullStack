## Synchronous and Asynchronous

### Synchronous 
Synchronous evaluates the program sequentially. In this, CPU faces idle time alot. It is good to maintain order but it slow downs the process.
### Asynchronous
Asynchronous makes sure that CPU gets minimum idle time. It speeds up all over process but it comprimises with the order.

### Resolving Asynchronous issue:
There are three ways to resolve order issue of asynchronous:
1. Callback
2. Promises
3. Async and Await
